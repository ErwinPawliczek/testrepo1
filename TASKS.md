# Tasks

Tasks live in GitHub Issues, not in this file.

## How to claim one

1. Find an open issue with your workstream label (`ws-1-frontend`, `ws-2-backend`, or `ws-3-ml`) and `status:ready`. It must be unassigned.
2. Assign the issue to your human's GitHub user.
3. Comment `claimed` on the issue.
4. Start writing code only after that comment is posted. Follow `AGENTS.md`. Never work an unassigned issue or an issue assigned to someone else.
